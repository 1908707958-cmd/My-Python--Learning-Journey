## 代码说明

### 1. bmi_calculator.py

核心是 `fun_bmi` 函数，接收三个参数：

| 参数       | 含义 | 单位 |
| -------- | -- | -- |
| `name`   | 姓名 | —  |
| `height` | 身高 | 米  |
| `weight` | 体重 | 千克 |

计算思路分两步：

1. 用公式 `bmi = weight / (height * height)` 算出 BMI 指数，即体重除以身高的平方；
2. 用四个 `if` 依次判断区间，输出对应的健康提示（世界卫生组织标准：低于 18.5 偏瘦，18.5～24.9 正常，24.9～29.9 偏重，29.9 以上肥胖）。

```python
def fun_bmi(name, height, weight):
    '''功能：根据身高和体重计算BMI指数'''
    bmi = weight / (height * height)
    print(name + '的Bmi指数为：' + str(bmi))

    if bmi < 18.5:
        print('你的体重过轻，ono')
    if bmi >= 18.5 and bmi < 24.9:
        print('你的体重在正常范围，good！')
    if bmi >= 24.9 and bmi < 29.9:
        print('你的体重过重')
    if bmi >= 29.9:
        print('有点肥胖')
```

最后两行是调用部分，分别用两组身高体重数据测试函数。

### 2. score_report.py

这个文件由两个函数组成，各负责一件事：

- `get_level(score)`：把一个分数转换成等级。用 `if` 从高到低判断，第一个满足条件的就 `return` 返回，所以 90 分以上返回"优秀"，80～89 返回"良好"，以此类推，都不满足时返回"不及格"。
- `average(scores)`：接收一个成绩列表，用 `for` 循环把每个分数累加到 `total`，最后除以 `len(scores)` 得到平均分。

```python
def average(scores):
    '''功能：接收一个成绩列表，返回平均分'''
    total = 0
    for s in scores:
        total = total + s
    return total / len(scores)
```

调用部分先用 `for s in scores` 遍历列表，逐个打印分数和对应等级，最后打印平均分。改写数据只需要改 `scores` 这个列表，函数本身不用动，这也是把逻辑封装成函数的好处。
